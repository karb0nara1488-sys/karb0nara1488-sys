# JobsPlugin

Плагин с двумя работами: **Грузчик** и **Фермер**. Взаимодействие с работами организовано через NPC и GUI.

## Возможности

- Работа грузчиком и фермером
- NPC для взаимодействия с работами
- GUI
- Настраиваемые фермерские поля
- Поддержка PlaceholderAPI
- Подключение экономики через Vault
- Поддержка Nexo

## Команды

| Команда | Назначение |
|---|---|
| `/npc` | Управление NPC работ |
| `/field` | Управление фермерскими полями |
| `/jobs reload` | Перезагрузка конфигурации |
| `/jobs test <loader|farmer>` | Тестирование работ |
| `/jobs economy` | Проверка экономики |
| `/barrels` | Создание груза для проверки работы грузчика |
| `/pos1`, `/pos2` | Выбор углов поля |

## Зависимости

- **Paper 1.21**
- **Vault** для подключения экономики (необязательно)
- **EssentialsX** или другой economy-provider при использовании Vault
- **Nexo** и **PlaceholderAPI** поддерживаются как дополнительные интеграции

## Разрешения

- `jobs.admin` администрирование, по умолчанию OP
- `jobs.use` использование работ, по умолчанию доступно всем

## Установка

1. Поместите `JobsPlugin.jar` в папку `plugins`.
2. При необходимости установите Vault и совместимый плагин экономики.
3. Перезапустите сервер.
